# 🌾 AgriProcure - Farmer Procurement & Mandi Management System

A modern, web-based **Farmer Procurement Management System** designed to streamline agricultural crop procurement, quality grading, MSP calculation, weighbridge management, and direct benefit transfer (DBT) payments to farmers.

## 🌟 Key Features

- **📊 Interactive Executive Dashboard**: Real-time stats on total procurement tonnage, farmer payouts, active registrations, and pending quality checks.
- **👨‍🌾 Farmer Directory & Registration**: Comprehensive farmer profiling with Bank A/C details, Aadhaar/ID verification, landholding size, and crop records.
- **🌾 Crop Procurement & Quality Grading**: Input crop intake, automatic moisture & impurity quality score calculation with grade assignment (Grade A, Grade B, Reject).
- **📈 Live MSP (Minimum Support Price) Ticker**: Dynamic pricing engine mapped to crop types and government support rates.
- **⚖️ Digital Weighbridge Integration**: Automatic net weight determination (Gross Weight - Tare Weight) with token generation.
- **💳 Direct Benefit Transfer (DBT) Payouts**: Automated payment calculation, approval workflow, and payment receipt generation.
- **🖨️ Printable Procurement Vouchers**: Professional invoice/receipt layout formatted for thermal and standard printing.
- **📈 Analytics & Export**: Graphical distribution of crop volume, village-wise procurement metrics, and local storage data persistence.

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/srinidhi6002/farmer-procurement-management.git
   ```
2. Navigate to the project directory:
   ```bash
   cd farmer-procurement-management
   ```
3. Open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).
